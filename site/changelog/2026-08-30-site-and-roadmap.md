DataPressr now has a published site — <https://datapressr-2-rufuspollock.flowershow.me> — with a landing page, a running "what to review now" list, and a datasets catalogue, built from `site/` with the Flowershow CLI. It also has a written roadmap to v1 (prove `structure` on a messy source → write 1–2 data stories by hand → pick a charting standard → write the `enrich`/`story` skills → ship the site) tracked in issues [#6](https://github.com/datasets/datapressr/issues/6)–[#13](https://github.com/datasets/datapressr/issues/13), and it started from a candid status pass that named what wasn't real yet: at that point only the validator was genuinely tested, `structure` had had one easy trial, and no data story existed. The rest of the same session then closed the first two of those gaps.
