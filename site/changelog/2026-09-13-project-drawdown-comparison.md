Following last week's relocation of this repo's own Project Drawdown dataset to `datasets/project-drawdown`, a second, unrelated Project Drawdown dataset turned up living inside `datasets/climate-and-environment` — same name, same GitHub org, different everything else. [The comparison](https://github.com/datasets/datapressr/blob/main/docs/project-drawdown-comparison.md) finds they're genuinely different products (2020's two-scenario Table of Solutions vs. 2024's richer, Explorer-based classification) rather than duplicates, and that only the 2024 one is actually published on DataHub. It also surfaces something worth a second look: the 2024 dataset states its licence as CC-BY-4.0, but a direct check of Project Drawdown's own terms of use turns up no such statement — the recommendation is to keep both datasets, cross-link them, and get that licence claim traced to an actual source before treating it as settled.
