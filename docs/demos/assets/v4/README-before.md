# Understanding atmospheric CO₂

This dataset tracks the globally averaged annual concentration of carbon dioxide in the atmosphere from 1979 onward, using NOAA’s marine boundary layer network.

## What is in the data?

- `year`: the year of the observation.
- `co2_ppm_mean`: the annual mean carbon dioxide concentration.
- `uncertainty`: the estimated uncertainty in that mean.

Source: NOAA Global Monitoring Laboratory.
