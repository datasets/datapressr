DataPressr now has a published site — <https://datapressr-2-rufuspollock.flowershow.me> — with a landing page, a running "what to review now" list, and a datasets catalogue, built from `site/` with the Flowershow CLI. It also has a written roadmap to v1 (prove `structure` on a messy source → write 1–2 data stories by hand → pick a charting standard → write the `enrich`/`story` skills → ship the site) tracked in issues [#6](https://github.com/datasets/datapressr/issues/6)–[#9](https://github.com/datasets/datapressr/issues/9), plus a candid status pass: only the validator is genuinely tested, `structure` has had one easy trial, and no data story exists yet.
