# DataPressr

**Tools for preparing and scaffolding datasets.**

---

## CLI

The `data` CLI (`cli-go/`) scaffolds new dataset directories locally.

```sh
data init my-dataset
```

See [docs/cli.md](docs/cli.md) for installation and full usage.

---

## Datasets

Candidate datasets and backlog live in `datasets/`.
