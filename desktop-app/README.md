# DataPressr desktop app

A workspace for creating datasets and data stories with an AI agent using the DataPressr skills, with data, documentation, charts and stories previewed beside the conversation. The agent changes the files; the app provides read-only previews.

BB is the initial host implementation. The product lives here so its identity and layout do not depend on that implementation choice.
